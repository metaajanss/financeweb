## Summary

This migration adds 6 missing columns to the existing `posts` table to support the multi-language blog system:

1. `featured_image_url` - Featured image for SEO and blog cards
2. `seo_title` - Custom meta title for SEO
3. `seo_description` - Custom meta description for SEO
4. `seo_keywords` - Array of keywords for SEO analysis
5. `reading_time_minutes` - Estimated reading time
6. `view_count` - Cached page view count

### Option 3: Manual SQL Execution

Connect to your Supabase database and run:

```sql
-- Add missing columns
ALTER TABLE public.posts
  ADD COLUMN IF NOT EXISTS featured_image_url TEXT,
  ADD COLUMN IF NOT EXISTS seo_title TEXT,
  ADD COLUMN IF NOT EXISTS seo_description TEXT,
  ADD COLUMN IF NOT EXISTS seo_keywords TEXT[],
  ADD COLUMN IF NOT EXISTS reading_time_minutes INTEGER,
  ADD COLUMN IF NOT EXISTS view_count INTEGER DEFAULT 0;

-- Add indexes
CREATE INDEX IF NOT EXISTS idx_blog_posts_slug ON public.posts(slug);
CREATE INDEX IF NOT EXISTS idx_blog_posts_published ON public.posts(published, published_at DESC);
CREATE INDEX IF NOT EXISTS idx_blog_posts_author ON public.posts(author_id);
```
